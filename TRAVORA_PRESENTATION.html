01 // Problem Statement

Transforming Enterprise Travel Coordination

Legacy travel management relies on disconnected spreadsheets, fragmented emails, and unverified PNRs.

❌ Legacy Travel Desk Pain Points

• Spreadsheet Chaos: Manual booking logs lead to lost PNRs and untracked ticket vouchers.

• Security Risks: Plaintext credential exposures, uncontrolled deletion, and unauthenticated chat channels.

• Approval Bottlenecks: Trips ticketed before manager authorization, causing budget overruns.

• Mass Movement Failure: No support for coordinating 50–100+ engineer site mobilizations.

✅ The Travora Solution

• Unified Single Pane of Glass: Seamless handoffs across Employee, Approver, and Travel Desk.

• Hardened RBAC & Document Vault: Bank-grade JWT authorization and secure ticket attachments.

• Automated Multi-Level Sign-Off: Live budget tracking, approver notes, and audit trails.

• Dedicated Bulk Movements: Master PNR rosters, seat allocations, and one-click manifest exports.

07 // Enterprise Security

7 Security Weaknesses Remediated

Full-spectrum security hardening conducted across authentication, authorization, and data privacy.

Security Vulnerability Remediated Severity Production Remediation Implemented
Privilege Escalation on Register Critical Public registration forces `ROLE_EMPLOYEE`; admin creation restricted to authenticated `POST /api/auth/users`.
Password Hash Serialization High Added `@JsonProperty(access = WRITE_ONLY)` on password field to eliminate leakage.
Global Mass Deletion Vulnerability High Locked down `DELETE /api/travel-requests/all` strictly to `hasRole('ADMIN')`.
Insecure Public `ntfy.sh` Broadcast High Decoupled public cloud topic in production (`if (API_BASE_URL) return;`) to protect confidential PNRs.
Production Startup Secrets Validation Medium JwtService enforces fail-fast startup check requiring strong 256-bit secret key on production profiles.
Missing Edge Security Headers Medium Configured strict HSTS (`max-age=63072000`), CSP, `X-Frame-Options: DENY`, and `X-Content-Type-Options`.
